## 📖 О проекте

**Tochka-Avtomatiki** — это комплексная веб-платформа, которая помогает компаниям оценить целесообразность роботизации их бизнес-процессов. Платформа предоставляет инструменты для подбора оптимальных роботизированных решений, расчёта экономических показателей и визуализации работы роботов на объекте.

---

## ️ Проблема

Компании, рассматривающие роботизацию, сталкиваются с двумя основными барьерами:

1. **Непонимание рынка** — информация о роботизированных решениях, их характеристиках и реальных показателях эффективности разрознена
2. **Сложность оценки ROI** — невозможность быстро оценить экономический эффект применительно к своему объекту

### Дополнительные вызовы:
- 📊 Рынок роботизированных решений фрагментирован
- 🎯 Вендоры дают оценки в свою пользу
- 🔍 Отсутствует независимый инструмент сравнения
- ⏱️ Решения об инвестициях откладываются или принимаются без достаточного обоснования

---

## 💡 Решение

Платформа **Tochka-Avtomatiki** предоставляет:

✅ **Единая база знаний** — каталог роботизированных решений с объективными характеристиками  
✅ **Быстрый расчёт экономики** — оценка OPEX, CAPEX, ROI и срока окупаемости  
✅ **Наглядная визуализация** — имитация работы роботов на вашем объекте  
✅ **Независимое сравнение** — объективные данные из открытых источников

##  Функциональность

### Шаг 1: Выбор отрасли и типа объекта

Пользователь выбирает категорию для роботизации:

- 🏭 **Торговля** — складские комплексы (с примерами данных)
- ✈️ **Логистика** — аэропорты и терминалы (с примерами данных)
- 🏥 **Социальная сфера** — медицинские учреждения (с примерами данных)
-  **Другое** — произвольный объект на усмотрение пользователя

### Шаг 2: Подборка и сравнение решений

Платформа показывает доступные на рынке решения:

-  Типы роботизированных решений
- 🤖 Отдельные продукты внутри каждого типа
- 📊 Ключевые характеристики и сравнительные показатели
-  Данные от организатора + информация из открытых источников

### Шаг 3: Расчёт экономики

Интерактивный калькулятор для оценки эффективности:

**Входные параметры:**
- Площадь объекта
- Объём операций
- Численность персонала
- Другие параметры объекта

**Расчётные показатели:**
- 💰 **OPEX** (операционные расходы)
- ️ **CAPEX** (капитальные затраты)
- 📈 **ROI** (возврат инвестиций)
- ⏰ **Срок окупаемости**
-  Потребность в ресурсах

### Шаг 4: Визуализация

Интерактивная 3D-имитация работы роботов:

- 🎬 Реалистичная симуляция процессов
- 📊 Отображение ключевых показателей в реальном времени
- 🔄 Возможность корректировки параметров

##  Установка

### Требования
- Python 3.9+
- Node.js 16+
- PostgreSQL 13+

### Локальная разработка

```bash
# Клонирование репозитория
git clone https://github.com/Limpery/Tochka-Avtomatiki.git
cd Tochka-Avtomatiki

# Установка backend зависимостей
cd backend
pip install -r requirements.txt

# Установка frontend зависимостей
cd ../frontend
npm install

# Настройка базы данных
# (инструкции по настройке БД)

# Запуск backend
cd backend
python main.py

# Запуск frontend (в новом терминале)
cd frontend
npm run dev
